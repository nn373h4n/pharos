## Security review and fixes

Independent review (a general-purpose agent given the `security-reviewer` instructions and the `security-checklist`; the project agents were not loaded in this session). No Critical or High.

- Medium, fixed: compose reads variables from the calling shell before the env file, so an exported `PHAROS_IMAGE_TAG` would re-tag a real installation's images and exported tokens would reach the throwaway worker. The script now drops every `PHAROS_*`, `POSTGRES_*` and `COMPOSE_*` variable first; a test exports four of them and checks that none reaches compose.
- Low, fixed: the `llm` network used the default subnet shared with other stacks (now 172.28.37.0/24); no lock against two runs (now `flock`, refused without touching anything); tests did not cover failures on the way (now: `compose up`, sign-in 401 and refused, a failed switch-on; all tear down); the `rmi` test now checks that only the two `:catalogue` images are removed; the broken-copy test for an ignored failure now runs the real assertion; the docs' cleanup claim is now precise (build cache and base images stay; nothing is removed after `SIGKILL`).
- Low, kept and documented: `curl -k` and the ports on all interfaces during the run, like the other throwaway stacks.
- Checked by hand: the EXIT trap runs on SIGINT and SIGTERM.

Checks: 25 tests PASS (three runs), `make lint` PASS. Not run: shellcheck (not installed on the host); the fixes were not run against the real stack again (they change only the environment, a lock and a subnet).
